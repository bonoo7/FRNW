## ✨ المميزات

### 1. **تقسيم منظم**
- كل فئة لها ملف منفصل
- سهولة البحث والتعديل
- إدارة أفضل للملفات

### 2. **توافق كامل**
- **لا تحتاج لتغيير أي شيء في التطبيق**
- جميع الأسئلة تُجمع تلقائياً
- العمل يستمر كما هو

### 3. **أداء محسّن**
- تحميل كسول (lazy loading) ممكن
- شحنات أصغر
- تحديثات فئات منفصلة

## 🚀 كيفية الاستخدام

### ✅ الطريقة الحالية (لا تغيير)

```javascript
// استيراد من الملف الأصلي - يعمل بدون تغيير
import { questions } from './data/questions.js';
```

### 📦 الطريقة الجديدة (متقدمة)

```javascript
// استيراد فئة واحدة
import جغرافياQuestions from './data/categories/جغرافيا.js';

// استيراد فئات محددة
import { جغرافياQuestions, تاريخQuestions } from './data/categories/index.js';

// استيراد جميع الفئات
import allQuestions from './data/categories/index.js';
```

## 🔧 التعديل والإضافة

### إضافة سؤال جديد

1. **الطريقة السهلة**: عدّل الملف المقابل مباشرة
   ```javascript
   // في data/categories/جغرافيا.js
   export const جغرافياQuestions = [
     // أسئلة موجودة...
     {
       "question": "سؤالك الجديد؟",
       "answer": "الإجابة",
       "category": "جغرافيا",
       "difficulty": "سهل",
       // ...
     }
   ];
   ```

2. **إعادة دمج الملفات** (إذا أضفت فئة جديدة):
   ```bash
   npm run split-questions
   ```

## ⚙️ البرامج النصية (Scripts)

في `package.json`:

```json
{
  "scripts": {
    "split-questions": "node scripts/split-questions.js"
  }
}
```

لتشغيل إعادة التقسيم:
```bash
npm run split-questions
```
