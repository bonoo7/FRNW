## 📋 نظرة عامة

**فكّر** هو تطبيق مسابقات ثقافية تفاعلي مصمم للعب الجماعي، يحتوي على مكتبة ضخمة من الأسئلة المتنوعة ونظام نقاط متطور يجعل التعلم ممتعاً ومشوقاً.

### ✨ المميزات الرئيسية

- 🎯 **9,619 سؤال** موزعة على **39 فئة** متنوعة
- 👥 **اللعب الجماعي** من 2 إلى 5 فرق
- 🏆 **نظام نقاط متقدم** مع مكافآت زمنية
- 🎨 **ثيمات متعددة** وتصميم متجاوب
- ⚡ **أداء سريع** وتجربة مستخدم سلسة
- 📱 **متوافق مع جميع المنصات** (iOS, Android, Web)

## 🚀 البدء السريع

### المتطلبات الأساسية

- Node.js 16+ 
- npm أو yarn
- Expo CLI

### التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/YOUR_USERNAME/FRNW.git
cd FRNW

# تثبيت الاعتماديات
npm install

# تشغيل التطبيق
npm start
```

### تشغيل التطبيق على منصات مختلفة

```bash
# تشغيل على الويب
npm run web

# تشغيل على Android
npm run android

# تشغيل على iOS
npm run ios

# تشغيل الخادم
npm run server
```

## 🏗️ البنية التقنية

### التقنيات المستخدمة

- **Frontend**: React Native 0.76.7 مع Expo 52.0.33
- **Navigation**: Expo Router 4.0.17
- **Backend**: Node.js مع Express.js
- **Storage**: AsyncStorage للبيانات المحلية
- **Styling**: React Native Paper + Custom Themes
- **Deployment**: Vercel للويب، Expo للهواتف

### هيكل المشروع

```
📁 FRNW/
├── 📁 app/           # صفحات التطبيق (Expo Router)
├── 📁 screens/       # شاشات التطبيق الرئيسية
├── 📁 components/    # المكونات القابلة لإعادة الاستخدام
├── 📁 services/      # خدمات البيانات والمنطق
├── 📁 data/          # قاعدة بيانات الأسئلة
├── 📁 contexts/      # إدارة الحالة العامة
├── 📁 styles/        # أنماط وثيمات التطبيق  
├── 📁 assets/        # الصور والملفات الثابتة
└── 📁 public/        # ملفات الويب العامة
```

## 🎯 الميزات المتقدمة

### نظام النقاط

- **النقاط الأساسية**: سهل (100)، متوسط (200)، صعب (300)
- **مكافآت السرعة**: حتى 20% نقاط إضافية للإجابات السريعة
- **نظام "علي وعلى أعدائي"**: مضاعفة النقاط ×5 للفريق الأخير

### نظام الثيمات

- ثيمات ملونة متعددة
- وضع داكن وفاتح
- تخصيص كامل للواجهة

### إدارة البيانات

- حفظ تلقائي للتقدم
- إحصائيات مفصلة
- تاريخ الألعاب السابقة

## 🛠️ التطوير والمساهمة

### إعداد بيئة التطوير

1. نسخ المشروع وتثبيت الاعتماديات
2. إنشاء ملف `.env` للمتغيرات البيئية
3. تشغيل `npm start` للبدء

### المساهمة في المشروع

نرحب بمساهماتكم! إليكم الخطوات:

1. Fork المشروع
2. إنشاء branch جديد (`git checkout -b feature/amazing-feature`)
3. Commit التغييرات (`git commit -m 'Add amazing feature'`)
4. Push إلى Branch (`git push origin feature/amazing-feature`)
5. فتح Pull Request

### إضافة أسئلة جديدة

```javascript

  "isDisabled": false
}
```
